# brokk-mj-tui

`brokk-mj-tui` is Mjolnir's Ratatui terminal frontend. It contains interactive
application state, rendering, input handling, onboarding, clipboard, speech,
and terminal lifecycle support.

This crate is primarily published so the Mjolnir workspace components can be
versioned and distributed together. Its Rust crate name is `mj_tui`, and its
API currently follows Mjolnir's release cycle rather than a separate stability
guarantee.

For installation and user documentation, see the
[Mjolnir repository](https://github.com/BrokkAi/mjolnir).
