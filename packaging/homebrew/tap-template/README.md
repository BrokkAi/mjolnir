# BrokkAi Homebrew tap

Official Homebrew tap for [Mjolnir](https://github.com/BrokkAi/mjolnir), the
forge-grade terminal client for any Agent Client Protocol (ACP) server.

`Formula/mjolnir.rb` is generated by the `Publish Homebrew` workflow in
BrokkAi/mjolnir on every release. Do not edit it by hand.

## Install

```bash
brew install BrokkAi/tap/mjolnir
```

Supported platforms: macOS (Apple Silicon and Intel) and Homebrew-on-Linux
x86-64/ARM64 (glibc). The formula installs `mj` together with its sibling
binaries `anvil` and `mj-voice-worker`; it does not install Bifrost (see
<https://mjolnir.brokk.ai/install/>).

## Upgrade and uninstall

```bash
brew upgrade mjolnir
brew uninstall mjolnir
```

Homebrew owns upgrades for this installation; do not use Mjolnir's in-place
self-updater under brew.
