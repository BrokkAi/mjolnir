# brokk-mj-anvil

`brokk-mj-anvil` registers the bundled Anvil ACP adapter used by Mjolnir's
Android build.

This crate is a platform integration component, not a standalone Anvil
distribution. Its Rust crate name is `mj_anvil`, and its API currently follows
Mjolnir's release cycle rather than a separate stability guarantee.

For installation and user documentation, see the
[Mjolnir repository](https://github.com/BrokkAi/mjolnir).
