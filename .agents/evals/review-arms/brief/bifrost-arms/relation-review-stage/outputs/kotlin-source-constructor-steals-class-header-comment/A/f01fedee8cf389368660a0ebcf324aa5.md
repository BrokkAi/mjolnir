- [P2] Preserve variadic overload layouts when matching arity — crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:2403-2412. When a Kotlin callable has multiple declarations and the selected overload has a `vararg` parameter, its persisted arity is variadic, but `is_variadic_parameter` always returns `None` for Kotlin. The reconstructed arity therefore never matches, so even an otherwise uniquely selected overload loses its formal layout and call bindings become unavailable; dispatch also cannot narrow to its body.
- [P2] Skip comments around Kotlin default expressions — crates/bifrost-jvm/src/kotlin/syntax.rs:496-504. Kotlin permits comments between a parameter and `=`, or between `=` and its expression. Tree-sitter retains these as siblings, so the first form is treated as having no default and the second returns the comment as the default expression. This produces missing or incorrectly located defaulted bindings, and can prevent overload layouts from matching their recorded arity.
