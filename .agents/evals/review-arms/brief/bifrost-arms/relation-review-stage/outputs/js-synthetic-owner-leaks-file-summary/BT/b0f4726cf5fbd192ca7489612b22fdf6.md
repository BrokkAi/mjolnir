- [P2] Preserve directory expansion for literal patterns — src/searchtools.rs:1348-1350
  When a literal pattern names an existing directory, `FilesystemProject::file_by_rel_path` returns it because it only checks existence. This branch now treats the directory as a file and skips `resolve_directory_target`, so `list_symbols` returns an empty entry for the directory instead of listing its analyzed files; `.` is affected as well. Restore a way to distinguish directories before accepting the lookup result.
