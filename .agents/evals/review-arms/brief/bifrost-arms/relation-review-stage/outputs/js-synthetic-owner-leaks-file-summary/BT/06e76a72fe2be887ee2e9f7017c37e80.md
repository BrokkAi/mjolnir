- [P1] Preserve directory expansion for literal patterns — src/searchtools.rs:1349-1352
  When `list_symbols` receives an existing directory such as `src` or `.`, `file_by_rel_path` returns a `ProjectFile` for the directory because the filesystem project checks only existence. This branch then skips directory expansion, so the result contains the directory as a zero-line file instead of its analyzed files. Restore a way to distinguish files from directories before taking the literal-file branch.
