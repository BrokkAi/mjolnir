- [P1] Preserve directory expansion for literal patterns — src/searchtools.rs:1349-1351
  When a literal pattern names an existing directory, the filesystem project implementations return it from `file_by_rel_path` because they check only whether the path exists. This branch now treats the directory as a file and skips `resolve_directory_target`, so `list_symbols` returns an empty entry for the directory instead of the symbols in its analyzed files; the same happens for the `.` pattern.
