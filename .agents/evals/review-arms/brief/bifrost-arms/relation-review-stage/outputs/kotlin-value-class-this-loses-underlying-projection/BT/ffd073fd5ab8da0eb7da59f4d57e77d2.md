If a parameter, local function, or callable local is named `Money`, a call such as `Money(raw)` resolves to that binding even when the file also declares a value class named `Money`. This lookup ignores those bindings and emits a construction transfer from the argument, so an arbitrary callable result is incorrectly modeled as the underlying value and subsequent boxing and projection facts are also wrong.
