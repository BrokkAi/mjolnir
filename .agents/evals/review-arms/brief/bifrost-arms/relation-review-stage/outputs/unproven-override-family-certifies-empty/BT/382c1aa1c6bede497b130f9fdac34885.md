- [P1] Preserve unproven hierarchy answers when discharging dispatch gaps — crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:554-557. When member-family analysis is incomplete, unsupported for the target language, or cancelled, `virtual_dispatch_implementor_targets` returns `Some(Vec::new())` rather than `None`. This arm therefore treats those unproven answers as proof that no overrides exist and removes the dynamic-dispatch gap. For an overridable target whose hierarchy could not be established, dispatch can consequently be reported complete despite missing possible targets, allowing downstream value-flow analysis to treat an incomplete binding as exhaustive.
