- [P2] Resolve each Rust use clause before recording its identifiers — src/analyzer/usages/rust_graph/extractor.rs:247-250. When a file imports the target as `Target` and also contains a separate nested scope with `use crate::other::Target`, `direct_names` contains `Target` for the whole file, so the unrelated import is reported as a reference to the target. The same name-based check also matches intermediate path segments. Resolve the particular use binding to the target before emitting its hit so references and rename do not include unrelated imports.
