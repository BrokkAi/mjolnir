- [P2] Resolve each Rust use path before recording its identifiers — src/analyzer/usages/rust_graph/extractor.rs:239-250. When a file imports `crate::target::Target` and also imports `crate::other::Target::Nested`, searching for the first `Target` reports the `Target` component of the unrelated second path as a reference. `direct_names` describes bindings for the whole file, so matching it against every identifier in every use declaration does not establish which declaration that identifier resolves to; the individual use path needs to be resolved before emitting the hit.
