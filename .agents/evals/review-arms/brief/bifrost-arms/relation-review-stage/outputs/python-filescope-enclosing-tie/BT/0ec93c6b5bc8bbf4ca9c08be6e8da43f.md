- [P2] Exclude import hits from the Java usage limit — src/analyzer/usages/java_graph/hits.rs:40-42. When a Java type is imported by more files than the usage limit, these newly recorded import hits trip `limit_exceeded` before they are classified as imports. The graph then returns `TooManyCallsites` even when there are few or no actual usages, so external usage search and call hierarchy fail despite their import-free surface.
- [P2] Resolve each Rust use path before recording its identifiers — src/analyzer/usages/rust_graph/extractor.rs:247-250. The names in `direct_names` describe bindings for the entire file, but this walk applies them to every identifier in every `use` path. For example, after importing the target `Target`, an unrelated `use crate::other::Target::Thing;` also reports its `Target` path component as a reference to the first target, even though it resolves to a different module. This produces incorrect LSP references for valid imports.
