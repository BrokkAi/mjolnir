- [P2] Resolve each Rust use path before recording its identifiers — src/analyzer/usages/rust_graph/extractor.rs:247-250
  When a file imports the target and also has an unrelated use such as `use crate::other::Target::Thing`, the `Target` path segment in the latter is accepted because it matches a file-wide direct binding name. References for the target therefore include an unrelated import; the same problem affects unrelated unaliased imports with matching intermediate segments. Match the individual structured use binding to the target instead of treating every identifier in the declaration as a local binding. [AGENTS.md:53](AGENTS.md#L53)

- [P2] Exclude Java import hits from the external usage limit — src/analyzer/usages/java_graph/hits.rs:40-42
  When a class is imported by more files than the usage limit, these import-only hits trigger `limit_exceeded` before they are reclassified, causing the graph to return `TooManyCallsites` and stop scanning even if there are few or no external usages. This also suppresses later real references, so the external usage surfaces are affected despite filtering import hits from successful results.
