- [P1] Preserve the scope of qualified Scala visibility — crates/bifrost-jvm/src/scala/resolution.rs:508-509: For declarations such as `private[pkg]` or `protected[Outer]`, the source visibility has already collapsed the qualifier into `Private` or `Protected`. Removing the visibility gap now lets the access policy treat those declarations as ordinary unqualified members, so valid references from the named package or enclosing scope are denied as complete results. Retain incomplete visibility until the qualifier is represented and evaluated.
- [P2] Allow protected access from a Scala companion — crates/bifrost-analysis/src/analyzer/store/resolution_operation/java_access.rs:237-241: When a companion object accesses a class's protected member (or vice versa), Scala permits the access, but this branch checks only whether an enclosing template is a subtype of the declaring template.
