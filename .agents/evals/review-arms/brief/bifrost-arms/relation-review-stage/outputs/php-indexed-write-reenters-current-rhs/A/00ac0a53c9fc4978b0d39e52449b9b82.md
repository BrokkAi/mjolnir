- [P1] Prevent recursive inference on self-referential indexed writes — crates/bifrost-php/src/graph/syntax.rs:1854-1858

  When a local collection contains an assignment such as `$items[] = $items[0]`, resolving a later `$items[0]->method()` makes collection inference inspect that assignment and resolve its right-hand subscript. The right-hand subscript starts after the assignment, so inference sees the same assignment again and recurses indefinitely, potentially overflowing the stack during analysis. The project requires stack-safe analyzer traversal ([AGENTS.md:502](AGENTS.md#L502)).

- [P2] Stop applying callback parameter types after reassignment — crates/bifrost-php/src/graph/syntax.rs:491-498

  In an `array_map` closure that reassigns its parameter before a member call, such as `function ($item) { $item = new Other(); return $item->run(); }`, this returns the original collection regardless of the intervening assignment. Both forward lookup and usage analysis can consequently attribute `run` to the collection element type instead of `Other`, producing incorrect definitions and inverse hits.
