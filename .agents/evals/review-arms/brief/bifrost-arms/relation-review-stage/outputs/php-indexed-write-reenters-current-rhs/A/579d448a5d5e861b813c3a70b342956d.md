- [P1] Avoid re-entering the same indexed assignment when resolving subscripts — crates/bifrost-php/src/graph/syntax.rs:1854-1858. If a local collection contains an assignment such as `$items[] = $items[0]`, resolving a later `$items[0]->method()` scans that assignment and resolves its right-hand subscript, which scans the same assignment again. This repeats until stack overflow and can terminate the analyzer process. The traversal must also satisfy the stack-safety requirement in [AGENTS.md](/workspace/7ee6a2450ba1430f59149b57a28c37cf/bifrost-dev/AGENTS.md:502).
- [P2] Account for callback parameter reassignment before inferring its receiver — crates/bifrost-php/src/graph/syntax.rs:1818-1822. In an `array_map(function ($item) { $item = new Other(); $item->method(); }, $items)` callback, this always assigns the collection element type to the later receiver even though the parameter has been overwritten. As a result, definition lookup and authoritative usages can report the element class's method instead of `Other::method`.
