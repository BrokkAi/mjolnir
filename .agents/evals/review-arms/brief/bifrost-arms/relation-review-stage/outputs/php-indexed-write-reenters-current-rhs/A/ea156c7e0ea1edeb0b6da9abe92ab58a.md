- [P2] Stop propagating the element type after a callback parameter is reassigned — crates/bifrost-php/src/graph/syntax.rs:475-479. In an `array_map` closure such as `function ($item) { $item = new Other(); return $item->method(); }`, this helper still identifies the later `$item` as the original collection element. Both definition lookup and usage analysis can consequently attribute `Other::method` to the collection element class, producing an incorrect definition and false usage hits. The callback binding needs to account for assignments before the reference.
- [P2] Match PHP function names case-insensitively — crates/bifrost-php/src/graph/syntax.rs:526-531. PHP function names are case-insensitive, but the builtin comparison and indexed shadow lookup use the spelling from the call. Consequently `ARRAY_MAP(...)` is not recognized as the builtin, and a namespace-local `function ARRAY_MAP(...)` can be missed when the call is spelled `array_map(...)`, incorrectly attributing callback parameters to the input collection even though the local function is called.
