- [P1] Invalidate conditional writes when no direct guard exists — crates/bifrost-rql/src/structural/search/effects.rs:2677-2694
  When a modeled call's result is ignored or stored without an immediately recognized guard, such as `errors.As(err, &exitError); exitError.ExitCode()`, the call is marked fully modeled but no edge write is installed. The scalar transfer therefore preserves the pre-call nil fact even though `errors.As` can populate the pointer, producing an erroneous exact nil-dereference finding. The same stale fact can also suppress a real finding when a modeled write changes a previously non-nil value.
