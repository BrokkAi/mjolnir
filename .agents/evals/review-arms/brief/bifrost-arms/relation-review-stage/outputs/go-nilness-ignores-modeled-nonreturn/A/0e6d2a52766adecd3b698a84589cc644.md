- [P1] Invalidate conditional writes when the result is not a direct guard — crates/bifrost-rql/src/structural/search/effects.rs:2677-2694
  When a modeled call's result is stored, ignored, or otherwise not used as the direct opaque guard, the call is still marked as having complete mutation handling but no edge write is recorded. For example, after `ok := errors.As(err, &exitError)`, `exitError` retains its prior nil fact even when `ok` is true, so a subsequent valid dereference can be reported as definitely nil; an initially non-nil target can likewise retain a stale fact. Invalidate the target at the call when its outcome cannot be represented by these edges.
