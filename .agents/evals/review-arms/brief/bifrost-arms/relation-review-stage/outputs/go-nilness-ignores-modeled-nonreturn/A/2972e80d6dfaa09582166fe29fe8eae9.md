- [P1] Invalidate conditional writes when the result is not a direct guard — crates/bifrost-rql/src/structural/search/effects.rs:2691-2694
  When a modeled call's result is ignored or first assigned to a variable, there is no direct guard edge, so this skips the write even though the call has already been marked as fully modeled. For example, `var e *exec.ExitError; errors.As(err, &e); e.ExitCode()` retains the initial nil fact even when `errors.As` sets `e`, producing a false positive; an initially non-nil target can similarly retain a stale non-nil fact. The target needs conservative invalidation when the outcome cannot be associated with edges.
- [P2] Invalidate pointees passed through local aliases — crates/bifrost-flow/src/scalar_state.rs:285-289
  When an address is stored in a local before an unmodeled call, such as `p := &value; mutate(p)`, the argument is a local value rather than an `Address`, so the call leaves `value`'s prior nilness unchanged even if `mutate` writes through `p`. Subsequent dereferences can therefore be reported or suppressed using a fact that no longer holds.
