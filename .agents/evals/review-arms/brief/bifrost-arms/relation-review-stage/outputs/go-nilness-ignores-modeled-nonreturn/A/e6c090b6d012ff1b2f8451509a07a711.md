- [P1] Invalidate conditional writes when the result is not directly guarded — crates/bifrost-rql/src/structural/search/effects.rs:2691-2694. When `errors.As(err, &target)` has its result ignored or stored before a later check, there is no direct guard edge, so the write is dropped even though the call was already added to `modeled_address_calls`. The scalar state consequently retains the old value of `target`: for example, a nil-initialized target is reported as definitely nil after a successful `errors.As`, producing a false positive in the error-severity policy. Conservatively invalidate the target at the call whenever the outcome-specific write cannot be placed on an immediately corresponding edge.
