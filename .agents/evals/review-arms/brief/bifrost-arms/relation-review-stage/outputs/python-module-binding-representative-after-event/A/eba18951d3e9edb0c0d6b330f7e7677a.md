- [P1] Preserve earlier bindings when a declaration is redefined later — crates/bifrost-analysis/src/analyzer/usages/get_definition/python.rs:1772-1779. When the same module name is assigned twice, such as `x = 1; print(x); x = 2`, the Python declaration collector uses `replace_code_unit` for the second field and retains only its later range. The first binding event therefore has no range ending before its activation, so this returns no candidates and the intervening reference stops resolving. The same regression affects repeated function or class definitions and assignment RHS references to a preceding same-kind binding.
