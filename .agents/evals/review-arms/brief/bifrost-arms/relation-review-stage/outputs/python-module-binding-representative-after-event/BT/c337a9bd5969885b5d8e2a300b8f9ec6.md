- [P2] Preserve class-local bindings when selecting module events — crates/bifrost-analysis/src/analyzer/usages/get_definition/python.rs:1771-1775
  When a module name is rebound in a class body, such as `x = 1; class C: x = 2; y = x` (with the class statements on separate lines), the class-local declaration is visible to `y` but ends after the module event's activation. This cutoff removes it and resolves `y` to the module declaration instead, producing incorrect definition, usage, and rename results for class-body references.

- [P2] Stop branch ancestry at deferred lambda bodies — crates/bifrost-analysis/src/analyzer/usages/get_definition/python.rs:1810-1813
  A lambda body is evaluated later, but its branch path continues through the enclosing `if`. For example, in a module-level loop that creates `f = lambda: x` in one arm and assigns `x` in the other on a later iteration, the assignment is discarded as incompatible even though `f()` observes it. This can turn a genuinely ambiguous deferred lookup into an incorrect resolved definition.
