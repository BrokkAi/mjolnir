- [P1] Preserve earlier bindings when a name is assigned again later — crates/bifrost-analysis/src/analyzer/usages/get_definition/python.rs:1771-1778. For `x = 1; print(x); x = 2`, the declaration collector replaces the first field CodeUnit with the second one, so its only stored range ends after the first binding event. This filter therefore returns no candidate for `print(x)`, even though the reference previously resolved. The same problem affects earlier functions with identical signatures that are redefined later; associating events with declarations requires retaining their physical ranges.
