- [P1] Preserve the completeness check before accepting a baseline — crates/bifrost-policy/src/coordinator.rs:209-216
  When `--accept-current` encounters an inconclusive policy, the new default makes the outcome exit 0, so its existing clean-status check overwrites the baseline with only the findings retained by the incomplete run. Previously it refused to write; missing existing findings can now be treated as new on subsequent scans, and the previous baseline is lost. Baseline acceptance needs its own completeness check independent of the advisory exit status.
