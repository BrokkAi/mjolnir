- [P1] Do not share incomplete Java class indexes across retained fills — crates/bifrost-analysis/src/analyzer/i_analyzer.rs:3311-3314. If a Java declaration read fails during one retained fill, `unique_class_by_fqn_in_file` still memoizes the resulting empty `JavaFileClassIndex` without retaining the failure. A later fill in the same request now reuses that index, records only the file read, and can retain an incorrect missing-class or return-type result without the original failure in its receipt. Previously each fill received a fresh memo, so the later fill retried the declaration read.
