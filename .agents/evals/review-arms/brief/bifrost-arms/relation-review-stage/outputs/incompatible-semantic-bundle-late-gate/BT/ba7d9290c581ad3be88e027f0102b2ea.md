- [P2] Wait for an in-progress catalog download before falling back — crates/bifrost-semantic-packs/src/download.rs:86-88. When concurrent preparations for different production keys share a catalog, the first caller claims the catalog and begins downloading, while the second immediately falls back to local production. If the second key is the JDK production contained in the bundle, it can start the expensive local build before the first caller finishes installing that very pack; the per-production locks do not serialize these different keys. Later callers should be able to wait for the catalog attempt and recheck its result.
- [P2] Avoid emitting an acquisition warning for every subsequent dependency — crates/bifrost-semantic-packs/src/download.rs:87-88. After the first attempt, every uncached dependency returns this error even when the bundle was downloaded and installed successfully but simply has no entry for that dependency. Projects with many dependencies therefore fill the bounded preparation diagnostics with misleading download warnings, suppressing useful producer diagnostics and reporting a download failure during normal local fallback.
