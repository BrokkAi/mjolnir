- [P1] Install only the requested exact production during automatic acquisition — crates/bifrost-semantic-packs/src/download.rs:248-249. When any dependency triggers a download, this installs every curated pack in the bundle before checking whether the requested generated key exists. Those packs become ordinary catalog candidates; for example, the curated JDK pack matches any JDK 21.0.8 evidence without an artifact digest, so a different JDK source archive can activate the downloaded Temurin models alongside its locally generated models. Thus a nonmatching download changes analysis results instead of safely falling back to exact local production.
