- [P1] Avoid installing unrelated packs before checking the requested key — crates/bifrost-semantic-packs/src/download.rs:248-250. When the first cache miss is for any dependency that is not the bundled JDK production, this installs every curated pack and generated production before discovering that the requested key is absent. Those persistent `PreShipped` packs are subsequently eligible for normal dependency activation, including dependencies without local artifacts, so a failed or nonmatching acquisition can silently change analysis results instead of falling back to the previous local behavior. Install only the matching exact production after establishing that the bundle contains it.
