- [P2] Wait for an in-flight catalog acquisition before falling back — crates/bifrost-semantic-packs/src/download.rs:86-88. When two workspaces in one process share a catalog and request different production keys concurrently, the second request is rejected as soon as the first claims the root, even though the first has not downloaded or installed the bundle yet. If the second request is the matching JDK production, its subsequent catalog recheck misses and it performs the expensive local build; the key-specific production locks do not serialize these different requests. The attempt needs to coordinate completion before other callers decide to fall back.
- [P2] Allow cancellation to interrupt release acquisition — crates/bifrost-semantic-packs/src/download.rs:91-91. When a workspace initialization is cancelled during a cold download, the synchronous callback has no cancellation token and continues through both HTTP requests, extraction, verification, and installation before preparation can observe cancellation. Each request has a separate 30-second timeout, so an unavailable or stalled release can keep a cancelled operation and its production lock occupied for up to roughly a minute.
