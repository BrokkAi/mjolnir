- [P2] Search each inheritance branch independently — src/analyzer/usages/get_definition.rs:3032-3034. In multiple inheritance, finding a member in one direct base stops the search through every other base, even when another branch inherits a different declaration of the same name at a greater depth. For example, if `D` inherits `A` and `B`, `A` declares `x`, and `B` inherits `C::x`, a lookup of `D::x` is ambiguous, but this returns only `A::x` and reports a definite resolution.
- [P2] Traverse deep inheritance chains without recursion — src/analyzer/usages/get_definition.rs:3036. A lookup for an absent member in a sufficiently deep inheritance chain makes one Rust call per base and can overflow the process stack, terminating the analyzer. The repository explicitly requires stack-safe traversal for analyzer graph walks ([AGENTS.md:41-44](/workspace/3a8acbe12b3ecb5a6224de083634ed2a/bifrost-dev/AGENTS.md:41)).
