- [P2] Search each inheritance branch independently — src/analyzer/usages/get_definition.rs:3032-3034. With multiple inheritance, finding a member in one direct base stops the search through every other base. For example, if `D` inherits from `A` and `B`, `A` declares `x`, and `B` inherits `x` from `C`, `D::x` is ambiguous, but this returns only `A::x` and reports a resolved definition.
- [P2] Traverse inheritance without recursive calls — src/analyzer/usages/get_definition.rs:3036-3036. A sufficiently deep inheritance chain with no matching member creates one Rust stack frame per level and can overflow the process stack during a definition lookup. The project explicitly requires stack-safe iterative traversal for analyzer graph walks ([AGENTS.md](/workspace/3a8acbe12b3ecb5a6224de083634ed2a/bifrost-dev/AGENTS.md:41)).
