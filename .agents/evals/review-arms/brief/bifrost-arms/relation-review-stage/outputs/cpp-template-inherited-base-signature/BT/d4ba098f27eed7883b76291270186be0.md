- [P2] Search each inheritance branch independently — src/analyzer/usages/get_definition.rs:3030-3033. When one direct base declares the member and another inherits a declaration from a deeper base, returning the first populated level discards the second branch. For example, if `B : A`, both `A` and `C` declare `x`, and `D : B, C`, lookup of `D::x` is ambiguous, but this returns only `C::x` as resolved.
- [P2] Resolve base aliases to their underlying class — src/analyzer/usages/get_definition.rs:3022-3025. When a class derives through a type alias such as `using Parent = Base; class Child : public Parent`, base resolution can return the alias unit, so the subsequent member lookup searches `Parent.member` and never visits `Base`. Inherited fields and methods therefore remain unresolved for this valid inheritance form.
- [P2] Traverse inheritance without recursive calls — src/analyzer/usages/get_definition.rs:3035-3035. A sufficiently deep inheritance chain with no matching member causes one Rust stack frame per base and can overflow the process stack during a definition query. The project explicitly calls for iterative analyzer graph traversal where depth is unbounded ([AGENTS.md:41-44](/workspace/4b864da96d47a89be16b7642723c90b4/bifrost-dev/AGENTS.md:41)).
