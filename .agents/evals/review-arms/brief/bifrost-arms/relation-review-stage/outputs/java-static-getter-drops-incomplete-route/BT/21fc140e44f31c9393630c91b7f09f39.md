- [P2] Preserve external boundaries for other owners of the same member — crates/bifrost-analysis/src/analyzer/store/resolution_operation/jvm_context.rs:3164-3165
  When a Java file imports a source-proven Kotlin alias and an external static member with the same name from different owners, adding the alias name to `indexed_static_import_members` causes the final filter to discard the external owner's boundary as well. A call can then be reported as completely resolved to the Kotlin declaration even though the external import may provide an applicable overload or make it ambiguous; the boundary needs to remain associated with its owner.
