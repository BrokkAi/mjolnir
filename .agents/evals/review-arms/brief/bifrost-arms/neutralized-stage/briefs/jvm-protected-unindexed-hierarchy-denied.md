## Value flow
- The added protected-access context contains caller templates and the declaration template (crates/bifrost-analysis/src/analyzer/resolution/fact_source.rs:90). Subtype evaluation reads `TypeObject` values from complete supertype-frontier states, treating other values or nonzero indirection as uncertain (crates/bifrost-analysis/src/analyzer/resolution/fact_resolution.rs:26568).
- The Scala analysis salt changes at crates/bifrost-analysis/src/analyzer/store/epoch.rs:1457; `compute_epoch` hashes the language salt (crates/bifrost-analysis/src/analyzer/store/epoch.rs:121), and `ensure_language_epoch` supplies the resulting epoch to the store's generation handling (crates/bifrost-analysis/src/analyzer/store/mod.rs:3552).
- `JvmAccessPolicy` takes Java package and outermost-type facts from `java_access_endpoints` (crates/bifrost-analysis/src/analyzer/store/resolution_operation/java_access.rs:43). That reader identifies an outermost type as an owner with a member scope and no parent-owner row (crates/bifrost-analysis/src/analyzer/store/resolution_typed/java_access.rs:36).
- Scala private access compares enclosing templates against companion pairs in either direction (crates/bifrost-analysis/src/analyzer/store/resolution_operation/java_access.rs:221). The companion reader selects persisted singleton relations of kind `companion` (crates/bifrost-analysis/src/analyzer/store/resolution_prepare/typed_rows.rs:229); Scala emits that kind for an object paired with a same-named sibling class or trait (crates/bifrost-jvm/src/scala/resolution.rs:2141, crates/bifrost-jvm/src/scala/resolution.rs:2174).
- The JVM endpoint query follows `resolution_member_owner_properties` and identifies templates through `resolution_member_scope_properties` (crates/bifrost-analysis/src/analyzer/store/resolution_typed/java_access.rs:73). Those tables are registered as resolution-bundle member-owner and member-scope relations (crates/bifrost-analysis/src/analyzer/store/resolution.rs:350).
- Scala visibility publication calls `source_visibility` and writes visibility rows (crates/bifrost-jvm/src/scala/resolution.rs:508). Its input mapping converts `Public`, `Protected`, and `NonApi` source facts to `Public`, `Protected`, and `Private`, respectively, and uses `Unknown` when no declaration fact matches (crates/bifrost-jvm/src/scala/resolution.rs:469).
