- [P1] Keep member candidates within the receiver's file — src/analyzer/usages/get_definition.rs:995-995. When two directories contain files with the same basename and each declares an object with the same name and property, their property FQNs are identical. The global FQN lookup therefore returns properties from both files even after the receiver was resolved to one specific file, making a valid lookup ambiguous or returning an unrelated definition.
- [P2] Resolve the called function in its lexical scope — src/analyzer/typescript/mod.rs:1036-1040. If an unrelated nested function has the same name as the function called by a top-level initializer, this searches both and accepts either as evidence of shape preservation. For example, an imported `wrap` that returns a different value is treated as an identity function merely because another scope declares `function wrap(x) { return x; }`, so properties are indexed on the wrong result.
- [P2] Require all return paths to preserve the argument — src/analyzer/typescript/mod.rs:1152-1154. A function such as `function wrap(x) { if (condition) return x; return {}; }` is considered shape-preserving because one return matches. Consequently `wrap({foo: 1}).foo` is reported as defined even when the actual returned object has no `foo` property.
- [P2] Do not treat z.object schema fields as result properties — src/analyzer/typescript/mod.rs:998-999. For the common Zod call `const schema = z.object({foo: z.string()})`, the result is a schema object and `foo` is a property of its shape, not of `schema` itself. Indexing it as `schema.foo` produces a false definition and incorrect skeleton; the same unconditional name check also applies to unrelated objects named `z`.
- [P2] Make function discovery stack-safe — src/analyzer/typescript/mod.rs:1075-1077. Any top-level call with an object argument triggers a recursive traversal of the entire file, so a deeply nested unrelated expression can overflow the Rust thread stack during workspace initialization. The repository explicitly requires iterative traversal for parser declaration collection ([AGENTS.md](/workspace/74fd1136bb880b03c84f4e1c2243e472/bifrost-dev/AGENTS.md:41)).
