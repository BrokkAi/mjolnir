- [P1] Do not apply scalar primitive conversions to array elements — crates/bifrost-analysis/src/analyzer/java/call_conversion.rs:466-468
  When an actual is `int[]` and a modeled formal is `long[]` (or `Integer[]`), recursively classifying the elements proves primitive widening (or boxing), even though Java permits neither conversion between those array types. This can select an inapplicable model overload and attach its identity and conversion evidence to the call, producing incorrect policy results.
