- [P1] Keep walk caches separate across project snapshots — crates/bifrost-analysis/src/analyzer/rust/mod.rs:102-105. When `clone_with_project` creates an overlay snapshot, it retains this shared cache even though it replaces the project and Cargo routes. A walk cached before the clone can therefore supply disk-project routes to the overlay, and a walk cached in the overlay can affect later disk queries. This can return incorrect usage and definition results when the projects have different Cargo routes or module files.
- [P2] Make export-chain traversal stack-safe — crates/bifrost-analysis/src/analyzer/rust/usage_walks.rs:1115-1116. A long chain of re-exports causes `bindings_at` to recurse once per edge, so a sufficiently deep workspace can overflow the thread stack and terminate the process. The depth is not bounded by the input. The project requires iterative traversal for usage analysis ([AGENTS.md](/workspace/135bdd6d8ae34955a21d8aeab34d8eae/bifrost-dev/AGENTS.md:394)).
