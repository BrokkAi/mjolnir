- [P2] Use an iterative walk for long re-export chains — crates/bifrost-analysis/src/analyzer/rust/usage_walks.rs:1115-1116. A long chain of modules that re-export a name makes `bindings_at` call itself once per module through `edge_targets`. The cycle check does not limit an acyclic chain, so usage discovery can overflow the thread stack and terminate the process. Alias resolution has the same risk. Use an explicit worklist, as required for usage graph walks by [AGENTS.md](/workspace/7a4a477c6ed3150032e17456bca60904/bifrost-dev/AGENTS.md:394).
