- [P1] Include module aliases in reverse import candidates — crates/bifrost-analysis/src/analyzer/rust/usage_walks.rs:935-938
  When a file imports `crate::alias::*` and `alias` routes to `crate::real`, the file need not mention `real` or any name declared in that module. It is therefore absent from the candidate set, even though its forward edge resolves to `real`. Usage discovery then misses that glob import and any uses or re-exports reached through it.
