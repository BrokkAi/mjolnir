- [P2] Preserve the selected component of a qualified constant — src/analyzer/usages/get_definition/ruby.rs:107-109. When the selected token is `Foo` in `Foo::Bar`, this unconditionally promotes it to the entire scope resolution and returns the definition of `Foo::Bar` instead of `Foo`. This also prevents rename target selection for the qualifier because the returned definition does not match the selected identifier.
- [P2] Respect Ruby's method lookup order for mixins and ancestors — src/analyzer/usages/ruby_graph.rs:380-398. A prepended module must take precedence over the class's own method, and a superclass's own method must take precedence over modules included by its superclass; this code always checks the receiver's direct methods first and then searches all ancestor mixins before any ancestor methods. Multiple included modules are also stored in an unordered set and returned together, so a valid call can become ambiguous instead of resolving to the last included module. Preserve the order required for semantic correctness ([AGENTS.md:68](/workspace/ff43e09f79837041ef70328ecefb4791/bifrost-dev/AGENTS.md:68)).
- [P2] Traverse earlier compound statements when collecting assignments — src/analyzer/usages/get_definition/ruby.rs:283-287. If a local is assigned inside an earlier compound statement, such as `begin; user = User.new; end`, the entire statement is skipped without visiting its assignment. A subsequent `user.audit` therefore has no inferred receiver and cannot resolve, even though the assignment executes before the call.
