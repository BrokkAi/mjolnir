- [P2] Include later let-chain conditions in binding activation — crates/bifrost-rust/src/structural.rs:427-431
  In a Rust let chain such as `if let Some(x) = opt && x > 0 { ... }`, `x` is also visible in the later condition. Restricting its activation to the consequence makes that reference resolve to an outer `x` or appear unresolved, so lexical-environment consumers can reach an incorrect binding or report incomplete results for valid chains.
