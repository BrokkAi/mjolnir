- [P2] Keep callable constants and statics in the value namespace — src/analyzer/usages/get_definition/rust.rs:897-900 — When a function pointer is stored in a `const` or `static`, such as `const HANDLER: fn() = handler; HANDLER();`, the focused identifier is classified as `Callable` but this predicate excludes its declaration. Definition lookup therefore fails for valid calls to indexed constants and statics, including imported ones.
- [P2] Resolve macros inherited from enclosing modules — src/analyzer/usages/get_definition/rust.rs:635-645 — An unqualified `macro_rules!` macro declared before a child module is textually visible inside that child, but the fallback searches only the current module and file. For example, `macro_rules! m { () => {} } mod child { fn f() { m!(); } }` now returns `no_definition` for `m!()` even though its indexed declaration is visible; the same problem occurs when the child is in another file.
