- [P2] Allow callable constants and statics in call position — src/analyzer/usages/get_definition/rust.rs:897-900. When a `const` or `static` holds a function pointer, a call such as `HANDLER()` is valid Rust, but the new callable filter excludes its indexed field declaration. Definition lookup now returns no definition (or an import boundary for an imported handler), which also prevents reference targeting and rename from resolving that use.
- [P2] Recognize nested free functions inside impl methods — src/analyzer/usages/get_definition/rust.rs:908-911. A function declared inside a method body is a free local item, even though an `impl_item` or `trait_item` is among its more distant ancestors. Rejecting every function with such an ancestor causes calls to these nested functions to lose their definition; the check needs to distinguish the function's immediate declaration scope from enclosing items.
