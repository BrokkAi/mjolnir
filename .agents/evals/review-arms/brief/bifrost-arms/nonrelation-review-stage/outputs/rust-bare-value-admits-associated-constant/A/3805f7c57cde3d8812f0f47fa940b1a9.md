- [P2] Restrict type-parameter detection to unqualified names — src/analyzer/usages/get_definition/rust.rs:414-415
  In a function such as `fn f<T>(x: foo::T)`, the final `T` is a qualified module type, but this check finds the unrelated generic parameter and returns `local_type_parameter` before scoped-path resolution runs. Looking up `foo::T` therefore loses its actual definition whenever an enclosing generic has the same name.
- [P2] Allow callable constants and statics — src/analyzer/usages/get_definition/rust.rs:897-900
  A Rust constant or static can hold a function pointer, so `const HANDLER: fn() = handler; HANDLER()` is a valid call whose definition is the constant. Classifying the callee as `Callable` now excludes all constants and statics, causing local calls to return no definition and imported calls to be reported as unindexed boundaries.
