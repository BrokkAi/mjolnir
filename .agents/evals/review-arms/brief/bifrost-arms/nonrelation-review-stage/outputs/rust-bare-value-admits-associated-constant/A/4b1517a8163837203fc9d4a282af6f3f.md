- [P2] Include callable constants and statics in call resolution — src/analyzer/usages/get_definition/rust.rs:897-900
  When a function pointer is stored in a module-level `const` or `static`, such as `const CALLBACK: fn() = handler;` followed by `CALLBACK()`, the callee is classified as `Callable` but this filter rejects its declaration. Definition lookup consequently returns no definition for a valid call that previously resolved through the value namespace.

- [P2] Follow imports in the target inline module's scope — src/analyzer/usages/get_definition/rust.rs:784-788
  When a child of an inline module imports a name privately imported by its parent, the parent and child share the same source file. Looking up the binder at `source.len()` selects the file's outermost module, so it misses the parent's `use` and cannot follow the import to its physical declaration. This breaks the newly supported parent-import resolution for inline modules.
