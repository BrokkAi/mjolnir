- [P2] Preserve callable constants and statics in name resolution — src/analyzer/usages/get_definition/rust.rs:897-900. When a function pointer is stored in a `const` or `static` and called as `HANDLER()`, the reference is classified as callable, but this filter excludes its declaration. Definition lookup now returns no definition, or an import boundary if the value was imported, even though the declaration is indexed.
- [P2] Do not treat qualified types as generic parameters — src/analyzer/usages/get_definition/rust.rs:415-420. In a function such as `fn f<T>(_: other::T)`, focusing the final `T` matches the enclosing generic parameter by name and immediately returns `local_type_parameter`. The qualified type refers to `other::T`, so this prevents lookup of its indexed declaration.
