- [P2] Count reused files separately from missing blob keys — crates/bifrost-mcp/src/workspace_progress.rs:74-74. When multiple files have identical content and their shared blob is not cached, the reconcile producer subtracts one missing blob key from the number of files, so a cold build of ten identical files reports nine reused files even though none were cached. Exposing that event as a file-based reuse counter gives clients materially incorrect progress; the producer must count files associated with missing blobs instead.
