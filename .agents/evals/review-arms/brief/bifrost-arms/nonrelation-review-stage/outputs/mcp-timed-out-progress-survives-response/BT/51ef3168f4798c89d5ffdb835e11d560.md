- [P2] Preserve the new binding's observation during a concurrent refresh — crates/bifrost-mcp/src/searchtools_service.rs:5873-5873. If a refresh has acquired the session write lock but is paused before this call, a concurrent workspace bind can start its new build observation and then block on that lock. The refresh then replaces that observation with one for the old workspace; after the bind installs the new workspace, its build callbacks and completion are ignored, so requests for the newly bound workspace receive no indexing progress. Coordinate observation creation with the binding/session transition so the older refresh cannot supersede the new build.
