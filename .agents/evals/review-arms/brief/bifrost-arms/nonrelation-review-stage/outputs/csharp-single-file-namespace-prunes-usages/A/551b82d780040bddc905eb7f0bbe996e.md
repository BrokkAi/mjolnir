- [P1] Include fully qualified static references in candidate files — src/analyzer/csharp_analyzer.rs:288-305
  When a file in another directory calls `Domain.Target.Run()` without a `using Domain` directive, the receiver is an expression rather than a type-position identifier, so this index does not include the file. The default candidate provider then never passes it to the graph, and usage lookup silently omits the call; the direct graph tests bypass this routing by supplying all files.

- [P1] Account for all requested overloads — src/usages/csharp_graph.rs:43-43
  When the caller supplies multiple overloads, the graph builds its specification solely from the first one and returns success, so calls matching the other overloads are silently omitted rather than reaching the regex fallback. This affects both methods and constructors with different parameter counts.

- [P2] Handle omitted optional and expanded params arguments — src/usages/csharp_graph.rs:344-350
  A valid call to `Run(int x = 0)` with `target.Run()` or to a `params` method with multiple arguments fails this exact arity check. The graph returns a successful result without these calls, and the same problem occurs in the constructor check.

- [P2] Keep namespace visibility specific to the reference — src/analyzer/csharp_analyzer.rs:150-159
  A C# file can contain multiple namespace declarations, but this selects one arbitrary declaration's namespace for the entire file. References in the other namespaces can therefore resolve to the wrong same-named type or be dropped, and same-namespace candidate selection can also exclude the file entirely.

- [P2] Respect lexical scopes while collecting receiver bindings — src/usages/csharp_graph.rs:470-475
  This walks every earlier subtree of the method, including blocks that have already ended. For example, a local `Target item` inside a completed `if` block is still seeded when a later sibling block declares `var item = GetOther()` and accesses it; depending on the later binding, this can report an unrelated member as a proven hit or cause valid hits to fall back. Bindings should reflect the scopes enclosing the access.

- [P2] Count arguments from syntax nodes rather than angle brackets — src/usages/csharp_graph.rs:770-773
  In a call such as `target.Run(a < b, c)`, the comparison opens `angle_depth` and never closes it, so the comma is ignored and a two-argument call is treated as one argument. Consequently valid method and constructor calls are silently missed when argument expressions contain comparisons.
