- [P2] Avoid caching fallback indexes in Scala project types — src/analyzer/tree_sitter_analyzer.rs:4028-4030. If building the definition index fails, this returns an empty index as though it were valid; `ScalaAnalyzer::project_types` then retains it in its own `OnceLock`. A transient SQLite read error therefore permanently removes project definitions from subsequent Scala hierarchy and resolution queries even after the store recovers. The same problem applies to the usage-facts fallback.
