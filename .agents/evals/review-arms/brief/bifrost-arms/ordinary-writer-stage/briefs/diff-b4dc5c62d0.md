- The callback nodes retained in `JsTsTestCase` (crates/bifrost-js-ts/src/test_detection.rs:14) belong to the tree created by `parser.parse`; that tree remains local while collection and all test analyses execute (crates/bifrost-js-ts/src/test_detection.rs:28).

- The changed analyzer supplies a test invocation's byte offset and collapsed callback-body excerpt for aggregate findings (crates/bifrost-js-ts/src/test_detection.rs:165); the shared aggregator uses those values for both zero-assertion and shallow-only results (crates/bifrost-core/src/analyzer/test_assertions.rs:125, crates/bifrost-core/src/analyzer/test_assertions.rs:164).

- AST classification feeds `classify_common_test_assertion` (crates/bifrost-js-ts/src/test_detection.rs:288), whose category mapping supplies names, configured scores and shallow status (crates/bifrost-core/src/analyzer/test_assertions.rs:34). - Each signal's call offset becomes a finding offset through the shared aggregator (crates/bifrost-js-ts/src/test_detection.rs:333, crates/bifrost-core/src/analyzer/test_assertions.rs:143).
