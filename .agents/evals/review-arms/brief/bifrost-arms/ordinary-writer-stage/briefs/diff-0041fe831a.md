## Value flow

- `ProcedureHandle::artifact` supplies the owning `Arc` (`crates/bifrost-analysis/src/analyzer/semantic/ir/artifact.rs:1384`); the new session key compares and hashes its allocation address (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:524`). Procedure-handle equality independently uses the same allocation identity plus procedure ID (`crates/bifrost-analysis/src/analyzer/semantic/ir/artifact.rs:1487`).
- Each session-map insertion clones the provider's oracle and retains the supplied artifact (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:623`, `crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:439`). Exact source later comes from `current_artifact_source`, with workspace-mount and artifact-key comparisons before returning the source (`crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:2607`).
- Dispatch outcomes from the session still feed read attribution (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:1506`); attributed keys enter the analyzer read ledger, and unattributed results mark an unattributed read (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:681`). Completed transfer replay records the stored attribution without resolving dispatch again (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:1466`).
- The session resolves against a cloned scalar budget (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:1496`); `SemanticRequest::staged` preserves cancellation, the execution ledger, and the artifact collector (`crates/bifrost-analysis/src/analyzer/semantic/provider.rs:919`). The outer scalar budget receives the staged budget only when the final outcome has an available value (`crates/bifrost-analysis/src/analyzer/semantic/icfg.rs:1730`).
- `retains_exact_source` reads `low_level_source_paid`, and `discard_exact_source` clears both that flag and the low-level session (`crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:172`). Ordinary dispatch sets the flag from committed source-byte work (`crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:262`); the declared-local-target route sets it after charging source and result work (`crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:386`).
