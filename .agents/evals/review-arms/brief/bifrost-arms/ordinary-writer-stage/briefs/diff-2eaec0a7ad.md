## Value flow
- The changed declaration-name helper sorts and deduplicates location ranges. It passes each range to AST name selection, including line-span selection (`crates/bifrost-analysis/src/analyzer/declaration_range.rs:101`, `crates/bifrost-analysis/src/analyzer/declaration_range.rs:128`).
- Location projections read current source through `current_source`. During a query, that function caches both text and `None` by `ProjectFile` (`crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3742`, `crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3721`).
- `structural_file_state` compares indexed and current text after CRLF normalization. It retains indexed state for other text differences; otherwise, it requests current-source state (`crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3747`, `crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3773`).
- The new current-source helper passes text to `fetch_file_state_from_source`. That function hashes the bytes; the cache key combines this hash with the relative path (`crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3768`, `crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3763`, `crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3390`).
- Current-source hydration supplies exact text to the store. The hydration path assigns it to `state.source` and caches the resulting `Arc<FileState>` (`crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3765`, `crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3855`, `crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3882`).
- Location selection derives its byte position from `indexed_source`. Module selectors compare that position with the new location ranges; other selectors compare name ranges (`crates/bifrost-analysis/src/searchtools/scan_usages.rs:1192`, `crates/bifrost-analysis/src/searchtools/scan_usages.rs:1233`, `crates/bifrost-analysis/src/searchtools/scan_usages.rs:1367`).
- `declarations_in_file` uses the new location declarations as traversal roots. It then adds same-file members through ordinary `get_members_in_class` calls (`crates/bifrost-analysis/src/searchtools/scan_usages.rs:1572`, `crates/bifrost-analysis/src/searchtools/scan_usages.rs:1578`).
