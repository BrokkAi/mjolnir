## Affected callers
- Typed evaluation calls `project_binding` and merges its values and completion into slot states (crates/bifrost-analysis/src/analyzer/resolution/fact_resolution.rs:24331); constructor-owner type objects now enter that same merge (crates/bifrost-analysis/src/analyzer/resolution/fact_resolution.rs:24704).
- `RustSupport::resolve_type_bounded` delegates to the changed native adapter (crates/bifrost-analysis/src/analyzer/rust/mod.rs:1810). General type lookup invokes this resolver with an optional tree and no cancellation token (crates/bifrost-analysis/src/analyzer/usages/get_type/mod.rs:396).
- Receiver queries inspect `target_kind` to select static receiver projection (crates/bifrost-analysis/src/analyzer/usages/receiver_query/mod.rs:1596); the adapter assigns `ValueExpression` for call and struct expression focuses (crates/bifrost-analysis/src/analyzer/rust/native_points.rs:700).
- `ensure_language_epoch` obtains the fingerprint and passes it into generation reconciliation (crates/bifrost-analysis/src/analyzer/store/mod.rs:3093); the expanded Rust salt (crates/bifrost-analysis/src/analyzer/store/epoch.rs:1004) is hashed by `compute_epoch` (crates/bifrost-analysis/src/analyzer/store/epoch.rs:109).
- Macro transcriber and static-path lowering also call `lower_scoped_expression_reference`, without consuming its returned slot (crates/bifrost-rust/src/resolution.rs:3559, crates/bifrost-rust/src/resolution.rs:3588); runtime receiver lowering consumes that slot (crates/bifrost-rust/src/resolution.rs:4528).
- Structural role extraction already uses `expression_name_node` for terminal callees, receivers, and positional arguments (crates/bifrost-rust/src/structural.rs:641, crates/bifrost-rust/src/structural.rs:646, crates/bifrost-rust/src/structural.rs:658); those consumers share its expanded struct, scoped-type, and generic-type handling (crates/bifrost-rust/src/structural.rs:124).

## Paths
- Receiver queries pass the prepared syntax tree and remaining budget to the resolver (crates/bifrost-analysis/src/analyzer/usages/receiver_query/mod.rs:1576), which derives the terminal-name locator (crates/bifrost-analysis/src/analyzer/rust/native_points.rs:655) before invoking `resolve_rust_type_for_caller_bounded` (crates/bifrost-analysis/src/analyzer/rust/native_points.rs:673).
- The primary walker invokes its enter callback before stacking children (crates/bifrost-rust/src/declarations.rs:814, crates/bifrost-rust/src/declarations.rs:834), and native enter lowers calls (crates/bifrost-rust/src/resolution.rs:692). An outer method call therefore registers a nested call's receiver destination (crates/bifrost-rust/src/resolution.rs:4318) before nested call lowering removes that entry (crates/bifrost-rust/src/resolution.rs:4189).
- Call lowering discharges pending let initializations before draining pending receiver destinations (crates/bifrost-rust/src/resolution.rs:4187). Let lowering registers those initializations by producer node ID (crates/bifrost-rust/src/resolution.rs:3833), so one produced call result can feed both routes.
- Field-value navigation reaches `lower_runtime_identifier_receiver` only for an identifier base; other base expressions take the local-gap branch (crates/bifrost-rust/src/resolution.rs:4455). Method-call navigation invokes the expanded helper for every non-`self` receiver (crates/bifrost-rust/src/resolution.rs:4272, crates/bifrost-rust/src/resolution.rs:4523).

## Value flow
- `lower_enum_variant` records the constructor's enum owner and publishes Value and Type namespace authorities (crates/bifrost-rust/src/resolution.rs:2091, crates/bifrost-rust/src/resolution.rs:2098). `project_binding` uses a single Constructor owner to produce a type object for `TargetTypeIdentity`, or a runtime value for declared-value and callable-result projections (crates/bifrost-analysis/src/analyzer/resolution/fact_resolution.rs:24696).
- Native lookup changes only the locator's byte range to the structured name (crates/bifrost-analysis/src/analyzer/rust/native_points.rs:665); outcome construction retains the supplied whole query site in `reference` (crates/bifrost-analysis/src/analyzer/rust/native_points.rs:1191).
- Nonempty call arguments produce a call-site `UnsupportedCallApplicability` gap (crates/bifrost-rust/src/resolution.rs:4399). Projection evaluation combines call-result residual completion with projected state (crates/bifrost-analysis/src/analyzer/resolution/fact_resolution.rs:24343); the native adapter includes frontier completion in its new diagnostic (crates/bifrost-analysis/src/analyzer/rust/native_points.rs:1065).
- `add_scoped_identifier` derives `bare_qualified_route` by excluding leading absolute, `crate`, `self`, and `super` anchors (crates/bifrost-rust/src/resolution.rs:973). That Boolean now gates final-prefix typed continuation for paths longer than two segments (crates/bifrost-rust/src/resolution.rs:1114).
- Nested call lowering creates a `CallResult` slot projected from the callee's callable-result type (crates/bifrost-rust/src/resolution.rs:4352). Pending receiver discharge transfers that slot into the outer member qualifier with `Preserve` (crates/bifrost-rust/src/resolution.rs:4194).
- Struct receiver lowering obtains identity from the AST `name` field (crates/bifrost-rust/src/resolution.rs:4529); the method-call transfer converts a `TargetTypeIdentity` input to a non-addressable runtime receiver (crates/bifrost-rust/src/resolution.rs:4306), and subsequent call construction copies the qualifier into the call's receiver slot (crates/bifrost-rust/src/resolution.rs:4368).
