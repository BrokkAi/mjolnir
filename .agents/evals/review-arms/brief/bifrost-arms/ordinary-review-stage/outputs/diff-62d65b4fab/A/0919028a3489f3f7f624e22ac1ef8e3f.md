- [P1] Require the entire package route before selecting a package member — crates/bifrost-analysis/src/analyzer/store/resolution_operation/jvm_context.rs:631-648
  When a Scala file in `package app` imports `io.k.Widget` and `app.Widget` also exists, the new relative route `app.io.k` falls back to the existing `app` package and selects its `Widget`, even though `io.k` was never resolved. That bridge makes the loop stop before trying the actual `io.k` route, so the import resolves to the wrong declaration. Only a package matching the complete owner route should supply a direct package member; shorter prefixes need member continuation instead.
