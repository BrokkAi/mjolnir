- [P2] Do not skip unresolved segments of a relative import path — crates/bifrost-analysis/src/analyzer/store/resolution_operation/jvm_context.rs:631-635. For a Scala file in package `app`, `import foo.Obj.Bar` tries `app.foo.Obj` and then `app.foo` as packages, but the latter lookup searches directly for `Bar` and ignores `Obj`. If `app.foo.Bar` exists, it can be bound to this import and prevent the actual `foo.Obj.Bar` route from being considered. Only a package prefix that accounts for the entire owner route can directly provide the imported member; shorter prefixes need member traversal.
- [P2] Search enclosing scopes for earlier Scala imports — crates/bifrost-analysis/src/analyzer/store/resolution_operation/jvm_context.rs:559-561. When an earlier import is in an enclosing scope, such as `import io.k.XMLUtils` at file scope followed by `object Use { import XMLUtils.Escapes.unescMap }`, the two imports have different scope heads, so this lookup cannot find the already resolved `XMLUtils` route. The nested import consequently fails even though the earlier import is visible there; the route lookup needs to follow lexical scope ancestry.
