- [P2] Look up earlier imports in enclosing scopes — crates/bifrost-analysis/src/analyzer/store/resolution_operation/jvm_context.rs:559-561
  When an import is declared inside an object or method and its head was imported in an enclosing scope, such as `import io.k.XMLUtils; object Use { import XMLUtils.Escapes }`, the lookup uses only the inner `source_scope_head` and cannot find the visible outer import. The resulting route is unresolved even though Scala lexical scope makes the earlier import available.

  For multiple imports in one file, `token.ordinal()` is the mount ordinal and is identical for every token, so this sort preserves the candidate reader's order rather than source order.
