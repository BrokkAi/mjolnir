- [P1] Preserve cross-file definition ordering in index verification — crates/bifrost-store/src/analyzer/store/mod.rs:13098-13103. When two matching definitions in different files have the same priority, inserting text above one can reverse their order because `definition_sort_key` compares absolute `first_start_byte` before the source path. This change ignores those offsets in both files' index digests, so the recorded index read verifies even though `definitions()` can now return a different first candidate, allowing a policy unit to reuse a stale resolution. Recording only per-file declaration order cannot detect this cross-file reorder.
