- [P1] Invalidate persisted class-set reads before changing their encoding — crates/bifrost-store/src/analyzer/store/read_keys.rs:361-369. When an existing workspace contains a persisted procedure-dispatch read, its start and end columns contain the old distinct byte offsets, so this new decoder rejects the row as corrupt. Class-set procedure surfaces and summaries also use this decoder, but their schema/cache identity is not bumped by the policy epoch change; loading such a surface records a query failure instead of treating it as a cache miss. Existing workspaces can therefore fail analysis after upgrading until their persisted cache is cleared.
