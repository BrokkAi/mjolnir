- [P1] Invalidate persisted dispatch reads before changing their encoding — crates/bifrost-store/src/analyzer/store/read_keys.rs:361-367. When an existing workspace contains class-set procedure surfaces or summaries written by the previous version, their ProcedureDispatch rows store distinct start and end byte offsets. The new decoder rejects those rows as corrupt, but the class-set cache identities were not changed and those caches use this same decoder independently of the policy substrate epoch. Consequently ordinary cache lookups record query failures, and existing summary rows cannot be replaced because publication first tries to decode them. Version or migrate these persisted cache entries so an upgrade treats the old encoding as a cache miss.
