- [P2] Record each call's own dispatch quality for replay crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/source.rs:119-128. When a source range selects multiple calls with different dispatch coverage or outcome quality, each recorded call is hashed using the aggregate quality and coverage of the entire source projection. Replay hashes that call's individual outcome via `one_call_dispatch_answer_digest`, so at least the calls whose individual quality differs from the aggregate fail verification even when nothing changed. This prevents reuse for ranges containing, for example, both an exhaustive and an unresolved call.
