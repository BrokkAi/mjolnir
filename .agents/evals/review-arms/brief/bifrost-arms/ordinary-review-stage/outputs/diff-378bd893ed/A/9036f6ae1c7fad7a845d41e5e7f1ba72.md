- [P1] Reject censuses that exceeded the candidate-file limit — crates/bifrost-analysis/src/analyzer/go/package_function_value.rs:98-99. When a variable has more than 1,000 candidate files, `find_usages` discards the query's `CandidateFilesBudgetExhausted` status and can return `Success` for only the admitted files. An assignment in an omitted file is then missed, so dispatch incorrectly treats the initializer as the exhaustive target and race analysis can omit effects of the assigned function. Use the query completion status when deciding whether the census is complete.
- [P2] Propagate the semantic request budget and cancellation to the census — crates/bifrost-analysis/src/analyzer/semantic/workspace_oracle/dispatch.rs:2101-2105. Each package-variable call launches a fresh workspace usage query with its own cancellation token and no source-byte budget after charging only one traversal unit. On a large workspace, repeated calls can each scan up to 1,000 files even when the semantic request has exhausted its budget or has been cancelled, causing unexpectedly long analyses and delayed cancellation.
