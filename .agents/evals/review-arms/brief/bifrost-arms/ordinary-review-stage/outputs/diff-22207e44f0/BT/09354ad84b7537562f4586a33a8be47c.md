- [P2] Bind the allocated receiver for JavaScript constructor functions — crates/bifrost-analysis/src/analyzer/semantic/oracle/call.rs:487-488. JavaScript supports `function Item(v) { this.value = v; }` followed by `new Item(x)`, but function declarations are inventoried as `ProcedureKind::Function` even when invoked with `new`. This check now excludes that candidate from the allocation binding that previously supplied its `this`, so receiver-based effects such as the assignment to `this.value` cannot propagate to the constructed object.
