When the indexed Git blob uses LF and the working file uses CRLF, `indexed_source` now returns the LF text, but `location_ranges` uses the CRLF projection. `scan_usages` computes its byte position and parses declaration names from `indexed_source`, then compares them with those CRLF ranges. Positions after the first line can therefore select the wrong declaration or fail to select one. The same mismatch affects declaration name recovery.
