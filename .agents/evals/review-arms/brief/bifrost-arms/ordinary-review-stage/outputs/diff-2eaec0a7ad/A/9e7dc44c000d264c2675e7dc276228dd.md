- [P2] Keep location source and ranges in the same byte coordinates — crates/bifrost-analysis/src/analyzer/tree_sitter_analyzer.rs:3383-3385

When the indexed source has LF endings and the working file has CRLF endings, this returns the indexed LF source, but `location_ranges` uses the CRLF projection. A location scan computes its byte position from the LF source and compares it with CRLF module ranges, so a column near the start of a module can fail to resolve. Declaration name lookup also applies the CRLF ranges to an LF syntax tree, which can select the wrong node.
