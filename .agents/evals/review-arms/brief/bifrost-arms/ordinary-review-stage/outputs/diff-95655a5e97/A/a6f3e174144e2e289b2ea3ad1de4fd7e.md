- [P2] Preserve C# generic arity when resolving selectors — src/analyzer/symbol_lookup.rs:400-406. A metadata selector such as `Widget`2` is normalized to `Widget` regardless of the declaration's actual type-parameter count, so a workspace containing only `Widget<T>` returns that unrelated declaration instead of reporting the selector as missing. The same issue affects generic methods and can make selectors for different arities resolve to the same source.
- [P2] Restrict Lombok fields to the annotated owner — src/searchtools.rs:2411-2421. When two source roots contain the same Java class FQN and only one class has a Lombok annotation, the accessor helper retrieves fields by FQN across both files and accepts them based on the annotated owner. Consequently an anchor to the unannotated file can return its field as the source of a nonexistent generated accessor, while an unanchored lookup can return both fields as a successful match.
