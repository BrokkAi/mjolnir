- [P2] Preserve C# generic arity when resolving selectors — src/analyzer/symbol_lookup.rs:401-406: When a selector specifies an arity that does not match a declaration, such as `Example.Widget`2` for `Widget<T>` or a non-generic `Widget`, stripping the suffix makes that declaration resolve successfully. C# permits types and methods with the same name and different generic arities, so this also loses the information needed to select the requested overload and can return the wrong source or an unnecessary ambiguity.
