- [P2] Preserve C# generic arity when matching selectors — src/analyzer/symbol_lookup.rs:402-405. When a selector specifies a different arity from the declaration, such as `N.Foo`2` for `class Foo<T>`, stripping the numeric suffix makes it resolve to that unrelated declaration. C# permits types and methods with the same name and different generic arities, so these selectors can also resolve to the wrong overload or report ambiguity instead of identifying the requested declaration; validate the arity against the structured declaration before treating the names as equivalent.
