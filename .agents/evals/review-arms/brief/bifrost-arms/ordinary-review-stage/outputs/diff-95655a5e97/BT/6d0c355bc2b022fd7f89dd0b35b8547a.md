- [P2] Validate C# generic arity before resolving a selector — src/analyzer/symbol_lookup.rs:400-407. When a metadata selector specifies an arity that does not match the declaration, such as `Foo`2` for `class Foo<T>` or `Foo`1` for a non-generic `Foo`, stripping the suffix resolves it to that unrelated declaration. This also makes differently aritied declarations indistinguishable when they coexist, so metadata selectors can return incorrect or ambiguous results instead of selecting the requested declaration.
