- [P2] Include procedure-boundary deletions in the changed scope — crates/bifrost-policy/src/taint_policy.rs:1525-1528. When an edit deletes a decorator immediately before a Python function, the deletion hunk is zero-width at the start of the remaining function. The strict interior check excludes that function, so its sinks are not evaluated and the run can report a complete empty result even though the function's behavior changed. The head position alone cannot distinguish this from a deletion in the preceding module gap; the base-side range is needed to identify the affected procedure.
