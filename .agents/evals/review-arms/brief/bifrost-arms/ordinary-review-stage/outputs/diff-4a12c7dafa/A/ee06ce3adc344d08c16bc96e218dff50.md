- [P2] Exclude nested edits from the module initializer's changed range — crates/bifrost-policy/src/taint_policy.rs:3024-3026. In JavaScript and TypeScript files with executable top-level statements, the synthetic module initializer spans the entire program, including function declarations. Consequently, editing a function or even a module comment marks that initializer as changed and admits every unrelated top-level sink as a root; those sinks can again introduce findings or semantic gaps into a narrowly scoped run. The overlap check needs to account for the initializer's actual owned statements rather than its enclosing program span.
