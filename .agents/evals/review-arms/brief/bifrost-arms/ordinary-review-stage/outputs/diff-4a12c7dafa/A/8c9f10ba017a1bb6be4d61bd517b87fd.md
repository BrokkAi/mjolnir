- [P1] Include deletions at the end of a procedure — crates/bifrost-policy/src/taint_policy.rs:1525-1528. In a language with indentation-delimited bodies, deleting the last statement of a function places the zero-width head hunk after the end of the remaining function node. The strict interior check therefore excludes the edited function, including any sink still in its body, and the scoped run can incorrectly report a complete result with no findings. The same problem occurs when a deletion lands exactly on a procedure boundary.
