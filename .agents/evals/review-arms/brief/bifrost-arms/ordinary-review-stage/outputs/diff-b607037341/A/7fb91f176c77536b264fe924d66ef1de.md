- [P2] Resolve overloaded subscripts before using the container type — crates/bifrost-analysis/src/analyzer/usages/get_definition/cpp.rs:8014-8018. When the receiver is a class with an overloaded `operator[]`, such as `items[i].compute()`, unwrapping the subscript types the receiver as the container rather than the operator's return type. This can resolve `compute` to an unrelated container member or fail to find the element's member, even though the expression is valid C++.
- [P2] Include pointer indirection when checking declaration agreement — crates/bifrost-analysis/src/analyzer/usages/get_definition/cpp.rs:8048-8051. When visible declarations of a qualified variable disagree between `T` and `T*`, both bindings have the same `unit`, so this comparison treats them as unanimous despite their different `indirection` values. The newly supported qualified receiver can consequently resolve a member using an arbitrarily chosen conflicting declaration instead of failing closed.
