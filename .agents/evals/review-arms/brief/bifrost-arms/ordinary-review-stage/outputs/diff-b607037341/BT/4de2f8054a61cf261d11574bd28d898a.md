- [P2] Resolve overloaded subscripts before using the container type — crates/bifrost-analysis/src/analyzer/usages/get_definition/cpp.rs:8014-8018
  When the argument is a class with an overloaded `operator[]`, the subscript expression has the operator's return type, not the class's type. For example, if `Container::operator[]` returns `Item&` and both classes define `compute`, `container[i].compute()` now resolves to `Container::compute` instead of `Item::compute`. The new arm applies the array/pointer assumption to every subscript, so it can return an incorrect definition for ordinary C++ container access.
