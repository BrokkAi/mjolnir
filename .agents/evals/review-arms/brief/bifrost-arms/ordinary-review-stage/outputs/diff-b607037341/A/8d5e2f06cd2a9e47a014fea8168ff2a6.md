- [P2] Resolve overloaded subscripts to their element type — crates/bifrost-analysis/src/analyzer/usages/get_definition/cpp.rs:8014-8019. For a class with an overloaded `operator[]`, unwrapping the subscript types the receiver as the container itself rather than the operator's return type. For example, if `Container::operator[]` returns `Item&`, `items[i].compute()` will resolve to `Container::compute` when that member exists, or remain unresolved when only `Item::compute` exists. The array and pointer shortcut needs to distinguish class subscripts and resolve their operator return type.
