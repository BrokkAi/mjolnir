- [P2] Resolve overloaded subscripts to their result type crates/bifrost-analysis/src/analyzer/usages/get_definition/cpp.rs:8014-8018
  When the subscripted object has an overloaded `operator[]`, its element type need not be the object's own type. For example, if `Container::operator[]` returns `Item&`, `container[0].size()` is now looked up on `Container` and can resolve to `Container::size` instead of `Item::size`. The unconditional unwrapping also affects ordinary containers such as vectors; subscript typing needs to account for the operator's return type before looking up the member.
