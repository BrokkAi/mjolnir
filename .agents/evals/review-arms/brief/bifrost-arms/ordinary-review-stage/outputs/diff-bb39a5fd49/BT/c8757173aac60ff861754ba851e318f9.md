- [P2] Ignore aliases inside generic type arguments when checking the outer type — crates/bifrost-analysis/src/analyzer/usages/get_definition/csharp.rs:562-562. For a reference such as `Box<ext::Widget>` where `Box` is a workspace type and `ext` aliases an external namespace, looking up `Box` now returns an import-boundary diagnostic. The boundary helper walks all descendants of the `generic_name`, so it mistakes the alias in the type argument for the qualifier of `Box` and exits before resolving the actual requested type.
