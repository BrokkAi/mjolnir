- [P2] Limit alias boundary checks to the referenced type's qualifier — crates/bifrost-analysis/src/analyzer/usages/get_definition/csharp.rs:562-562. When a workspace generic type is referenced as `Container<ext::ExternalType>`, the lookup for `Container` promotes the whole generic name, and the boundary helper searches its type arguments too. An external alias in an argument therefore causes the lookup for the indexed `Container` itself to return `unresolvable_import_boundary` instead of its definition. The qualifier check needs to distinguish the referenced type's own name from aliases nested in its generic arguments.
