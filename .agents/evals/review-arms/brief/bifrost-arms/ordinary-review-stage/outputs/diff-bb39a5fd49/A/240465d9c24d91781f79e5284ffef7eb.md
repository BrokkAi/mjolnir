- [P2] Restrict the alias boundary check to the referenced type — crates/bifrost-analysis/src/analyzer/usages/get_definition/csharp.rs:562-568. For a workspace generic type such as `Container<ext::ExternalType>`, looking up `Container` passes the entire generic node to the boundary check, which traverses into its type arguments and finds the external alias. The lookup therefore reports an import boundary instead of resolving the indexed `Container`, even though the alias belongs to a different reference.
- [P2] Skip comments before the anonymous member assignment token — crates/bifrost-csharp/src/graph/extractor.rs:1091-1094. In valid code such as `new { Name /* comment */ = value }`, the comment is the identifier's next sibling, so `Name` is not recognized as a declaration. Definition lookup and usage extraction can consequently treat the output name as a reference to an unrelated in-scope `Name`.
