- [P2] Restrict alias boundary detection to the referenced type name — crates/bifrost-analysis/src/analyzer/usages/get_definition/csharp.rs:562-563. When a workspace type has an external alias-qualified generic argument, such as `Container<pb::Message>`, looking up `Container` incorrectly returns an import-boundary result. The boundary helper walks every descendant of the generic name, so it treats the argument's alias as evidence that the outer type itself is external, before attempting to resolve the indexed `Container`.
- [P2] Skip comments when identifying anonymous-object member names — crates/bifrost-csharp/src/graph/extractor.rs:1092-1095. In valid C# such as `new { Name /* comment */ = value }`, the comment is the identifier's next sibling, so the declared output name is not recognized and can be resolved as an unrelated workspace reference. The check needs to account for extra nodes between the name and the equals token.
