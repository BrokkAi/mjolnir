- [P2] Limit the alias boundary check to the referenced type — crates/bifrost-analysis/src/analyzer/usages/get_definition/csharp.rs:562-562
  When a workspace generic type has an external alias-qualified type argument, such as `Container<ext::Item>`, looking up `Container` traverses the entire generic syntax and finds `ext::Item`. The new check then returns an import-boundary diagnostic instead of resolving the indexed `Container` declaration. The alias boundary belongs to the type argument, not the generic type being queried.
