- [P2] Preserve unavailable evidence dimensions as null — crates/bifrost-rql/src/structural/search/witness_projection.rs:75-78. When an absent-member witness cannot be retrieved, this initializer is returned with `proof: "unproven"` and `completeness: "partial"` even though neither dimension was established; the error branch only adds a reason. Consumers therefore cannot distinguish unavailable evidence from an actually unproven, partial witness, contrary to the requested null-dimension contract. The evidence type and client models also need to permit null for this case.
- [P2] Do not describe incomplete results as incomplete semantic input — crates/bifrost-rql/src/structural/search/value_flow.rs:701-707. When semantic input is complete but the overall result is incomplete and the solver exhausts its budget or is cancelled, this maps the semantic input to `partial`; `combine_solver_and_semantic_reason` then publishes `semantic status partial` even though the original semantic status was `complete`. This gives consumers a false cause for the incomplete result and loses the distinction the new status/reason pair is meant to preserve.
