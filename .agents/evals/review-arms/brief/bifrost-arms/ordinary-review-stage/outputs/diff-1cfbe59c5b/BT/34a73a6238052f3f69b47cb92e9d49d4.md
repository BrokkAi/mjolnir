- [P2] Preserve complete semantic input when the solver stops early — crates/bifrost-rql/src/structural/search/value_flow.rs:701-707. When semantic input is complete but the solver exhausts its budget or is cancelled, `result.is_complete()` is false because it includes solver termination. This maps the semantic input to `partial`, so the final solver status reason falsely reports incomplete semantic evidence and loses the previously published `semantic_status: complete`. Derive the semantic status independently of solver completion before combining the outcomes.
