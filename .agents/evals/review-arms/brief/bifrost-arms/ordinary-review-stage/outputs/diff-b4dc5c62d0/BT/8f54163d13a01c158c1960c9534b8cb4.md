- [P2] Avoid treating repeated calls as self-comparisons — crates/bifrost-js-ts/src/test_detection.rs:264-269. When both operands contain the same call expression, such as `expect(counter.next()).toBe(counter.next())`, structural equality classifies the assertion as a self-comparison even though the calls execute separately and can return different values. These nested-call assertions were not recognized by the previous matcher, so the change introduces false high-severity smell findings for meaningful comparisons.
