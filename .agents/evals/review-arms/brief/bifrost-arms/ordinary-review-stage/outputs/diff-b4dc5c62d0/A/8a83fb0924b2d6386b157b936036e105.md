- [P2] Avoid treating repeated calls as self-comparisons — crates/bifrost-js-ts/src/test_detection.rs:264-269
  When both operands contain the same call, such as `expect(counter.next()).toBe(counter.next())`, the calls execute separately and can produce different values or side effects. The new structural comparison labels this a self-comparison with a tautology score, even though it is a meaningful assertion; nested calls were not classified this way by the previous detector.
