- [P2] Avoid treating repeated calls as self-comparisons — crates/bifrost-js-ts/src/test_detection.rs:264-269

  When both operands contain the same call expression, such as `expect(next()).toBe(next())`, structural equality labels the assertion a self-comparison even though the calls are evaluated separately and can return different values. These nested-call assertions were not previously classified this way, so valid tests can now receive a high-severity tautology finding; expression identity alone does not establish that repeated evaluations have the same value.
