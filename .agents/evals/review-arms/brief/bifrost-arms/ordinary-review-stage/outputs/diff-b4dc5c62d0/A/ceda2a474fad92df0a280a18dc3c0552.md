- [P2] Avoid treating repeated calls as self-comparisons — crates/bifrost-js-ts/src/test_detection.rs:264-269
  When both operands contain the same call, such as `expect(next()).toBe(next())`, matching syntax does not imply matching values: each call is evaluated separately and can return a different result or have side effects. The new support for nested calls therefore reports these valid checks as self-comparisons with a tautology score, even though the previous detector did not recognize the outer assertion. Only classify expressions as self-comparisons when their evaluation can be assumed to yield the same value.
