- [P2] Avoid treating repeated calls as self-comparisons — crates/bifrost-js-ts/src/test_detection.rs:265-269. When both operands contain the same call, such as `expect(counter.next()).toBe(counter.next())`, structural equality marks the assertion as tautological even though the calls run separately and can return different values. The new AST handling now admits these nested calls, so valid tests receive a high-scoring self-comparison finding; restrict this classification to expressions whose repeated evaluation can be assumed to yield the same value.
- [P2] Preserve equality detection for parenthesized assert operands — crates/bifrost-js-ts/src/test_detection.rs:342-343. For `assert.strictEqual((value), value)` (and similarly parenthesized literals), the old normalization stripped enclosing parentheses and reported self-comparison or constant-equality. The AST comparison instead rejects the `parenthesized_expression` against the unwrapped operand and treats the assertion as meaningful, hiding an existing smell.
