- [P1] Preserve fallback identities for complete-empty supertype answers — crates/bifrost-analysis/src/analyzer/resolution/selected_context.rs:1568-1570. When a Java class extends an implicitly imported type whose scope answer is complete and empty, such as `extends Thread` with a durable `java.lang.Thread` owner, this filter prevents `cached_hierarchy_reference_parts` from seeing the fallback identity. That path then uses the empty scope answer and builds a hierarchy edge with no target, so inherited members and subtype relationships from the external owner are lost even though the owner is indexed. The hierarchy lookup needs to consult the fallback after checking the selected answer, just as the type projection does.
