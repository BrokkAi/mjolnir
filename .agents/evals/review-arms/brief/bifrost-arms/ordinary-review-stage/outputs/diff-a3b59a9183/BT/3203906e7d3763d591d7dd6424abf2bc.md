- [P1] Preserve fallback identities for unresolved Java supertype edges — crates/bifrost-analysis/src/analyzer/resolution/selected_context.rs:1567-1569. When a Java superclass such as `Exception` has a complete-empty scope answer and is registered as an implicit fallback, hierarchy construction still calls this getter in `cached_hierarchy_reference_parts`. Filtering out the fallback makes that path return the empty scope targets instead of the external owner, so the superclass edge disappears and inherited member lookup and subtype checks miss the external hierarchy. The selected scope answer must still take precedence when it contains a source declaration, but complete-empty hierarchy answers need the fallback identity.
