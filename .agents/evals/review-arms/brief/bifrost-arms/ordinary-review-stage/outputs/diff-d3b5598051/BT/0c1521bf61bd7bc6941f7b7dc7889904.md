- [P2] Do not match persisted import identities against an edited mount — crates/bifrost-analysis/src/analyzer/store/resolution_operation/rust_reverse_gap_candidates.sql:61-65. When a file has an unsaved or otherwise changed mounted blob, `placement.summary_id` and `member_ordinal` refer to the persisted blob, while `imported` belongs to the mounted blob. Import IDs and route ordinals are blob-local, so an unrelated persisted resolved import can coincidentally match an unresolved import in the edited file. This suppresses the alias from the name closure and can omit reverse-reference candidates and completeness gaps. The same comparison occurs in the other alias branches.
