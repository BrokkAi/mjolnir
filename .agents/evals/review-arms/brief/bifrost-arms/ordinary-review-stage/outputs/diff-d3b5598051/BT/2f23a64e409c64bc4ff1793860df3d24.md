When a mounted file has unsaved changes, `imported` describes the mounted blob while the summary route and its import IDs and ordinals describe `placement.placement_blob`. These blob-local IDs can coincide after an edit even when they refer to different imports, so an unrelated persisted route can suppress an unresolved alias from the name closure, causing reverse-reference candidates and completeness gaps to be missed. The previous join required the route's blob to equal `imported.blob_id`; the same issue affects the other three replacement joins.
