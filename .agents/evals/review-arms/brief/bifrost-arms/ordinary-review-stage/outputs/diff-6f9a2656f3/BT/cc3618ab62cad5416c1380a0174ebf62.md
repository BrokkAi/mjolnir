- [P1] Avoid retaining every resolved import set at once — src/analyzer/capabilities.rs:70-73. In a project where many files wildcard-import a module with many declarations, this collects a full cloned `CodeUnit` set for every importer before constructing the reverse index, so peak memory grows with the number of importers times the number of declarations. The previous reverse lookup processed candidates one at a time, and the weighted forward cache cannot limit this temporary vector; a single reverse lookup can therefore exhaust memory on a large repository even though the resulting index contains only one file edge per importer.
