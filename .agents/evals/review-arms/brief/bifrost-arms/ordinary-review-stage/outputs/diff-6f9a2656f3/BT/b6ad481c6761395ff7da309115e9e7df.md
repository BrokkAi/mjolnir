- [P2] Avoid retaining every resolved declaration while building the index — src/analyzer/capabilities.rs:69-72. On repositories with many wildcard or package imports, each forward result can contain every declaration in the imported files, and this collection holds all of those sets simultaneously before reducing them to file-level edges. This bypasses the configured memo-cache budget and can make a single reverse lookup consume orders of magnitude more memory than the resulting index, potentially exhausting memory on large projects; the previous lookup processed one candidate at a time.
