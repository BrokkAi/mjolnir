- [P1] Avoid resolving every Go file on the first reverse lookup — src/analyzer/go_analyzer.rs:230-232. In a large Go repository, this now calls `imported_code_units_of` for every analyzed file, and that method scans `all_files` for each import. The previous reverse lookup first checked each import against the requested target and only performed that repository-wide scan for matching candidates. Consequently, even a single reverse lookup now incurs quadratic work in common projects with imports, which can make the operation substantially slower or time out.
