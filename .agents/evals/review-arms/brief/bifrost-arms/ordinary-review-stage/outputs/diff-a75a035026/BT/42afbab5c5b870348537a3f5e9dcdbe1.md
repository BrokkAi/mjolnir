- [P1] Account for package-level panic declarations in other files — crates/bifrost-analysis/src/analyzer/go/semantic.rs:1179-1188. When another file in the same Go package declares `func panic(v int)`, a call to `panic(x)` in this file invokes that function, but the shadowing inventory is built only from the current file. This guard therefore treats the call as the builtin, removes its call site and normal continuation, and emits a throw instead, losing the callee's behavior and all subsequently reachable code.
