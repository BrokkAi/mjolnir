- [P1] Account for package-level panic declarations in other files — crates/bifrost-analysis/src/analyzer/go/semantic.rs:1179-1180

  When another file in the same Go package declares `func panic(v any)`, this file's `package_shadowing` does not see that declaration because it is collected only from the current syntax tree. A call to that function is therefore lowered as the builtin throw, removing its normal continuation and call site and producing incorrect control-flow and taint results for valid multi-file packages.
