- [P1] Account for package-level panic declarations in other files — crates/bifrost-analysis/src/analyzer/go/semantic.rs:1179-1185. When another file in the same Go package declares `func panic(...)` or a package variable named `panic`, this file's procedure enumeration does not see that binding, so a call to it is incorrectly lowered as the builtin throw. The actual callee and its normal continuation disappear, which can hide both its side effects and all subsequent reachable behavior.
