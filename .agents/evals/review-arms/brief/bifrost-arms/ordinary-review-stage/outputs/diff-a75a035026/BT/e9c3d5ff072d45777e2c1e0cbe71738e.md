- [P1] Account for package-level panic declarations in other files — crates/bifrost-analysis/src/analyzer/go/semantic.rs:1178-1180
  When another file in the same Go package declares `func panic(v any)`, calls to `panic(v)` in this file invoke that function, but `package_shadowing` is collected only from the current file. This guard therefore lowers the call as a builtin throw, removes its normal continuation and call site, and can make subsequent reachable code and its data flows disappear from the analysis.
