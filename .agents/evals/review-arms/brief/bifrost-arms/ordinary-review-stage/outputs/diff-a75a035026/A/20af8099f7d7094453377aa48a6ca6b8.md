- [P1] Resolve package-level panic bindings across files — crates/bifrost-analysis/src/analyzer/go/semantic.rs:1179-1185. When another file in the same Go package declares `func panic(v int)` or a package variable named `panic`, this check does not see that binding: `predeclared_shadowed` is collected only from the current file and `binding_value` covers local bindings. A call to that function is consequently lowered as an unconditional throw with no normal continuation or call site, making subsequent code unreachable and losing its call semantics. Package-scope bindings must be considered across all files before treating the identifier as the builtin.
