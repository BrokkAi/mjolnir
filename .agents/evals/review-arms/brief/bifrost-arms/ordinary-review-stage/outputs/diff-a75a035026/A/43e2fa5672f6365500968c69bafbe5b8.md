- [P1] Resolve package-level panic bindings across files — crates/bifrost-analysis/src/analyzer/go/semantic.rs:1179-1185. When another file in the same Go package declares `func panic(...)` or a package variable named `panic`, this file's procedure inventory cannot see that binding, so a call to it is incorrectly lowered as an unconditional builtin throw. This removes the call site and makes the rest of the procedure unreachable, producing incorrect control-flow and taint results for valid multi-file packages.
