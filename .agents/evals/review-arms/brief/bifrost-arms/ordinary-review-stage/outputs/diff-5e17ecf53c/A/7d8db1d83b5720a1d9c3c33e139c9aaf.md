- [P2] Stop recovery tails at the end of the macro directive — src/analyzer/usages/get_definition/cpp.rs:3964-3969
  When a normal function-like macro with a value is immediately followed by a malformed top-level declaration or expression, an identifier inside that wrapper's `ERROR` node is now classified as part of the macro, even though the directive has already ended. The backward walk treats any error-bearing wrapper as a continuation without checking whether it belongs to the directive, so definition lookup returns `no_definition` for unrelated references in incomplete code. The clean-declaration boundary test does not cover this adjacent case.
