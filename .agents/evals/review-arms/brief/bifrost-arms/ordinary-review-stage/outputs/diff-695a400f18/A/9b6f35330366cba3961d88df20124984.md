- [P2] Preserve typed continuations for explicitly anchored enum paths — crates/bifrost-rust/src/resolution.rs:1114-1115
  For paths such as `crate::State::Unit` or `self::State::Tuple`, the new condition suppresses the typed continuation from `State` to the variant. The remaining root route treats `State` as a module, but enum variants live in the enum's type-member scope, so these paths lose the variant binding that the previous continuation provided. This also prevents the newly supported direct receiver forms from resolving when the enum path has an explicit anchor.
