- [P2] Preserve type continuation for explicitly anchored enum paths — crates/bifrost-rust/src/resolution.rs:1114-1115
  When an enum variant is referenced through an explicit anchor, such as `crate::State::Unit` or `self::module::State::Unit`, this condition no longer creates the typed continuation from `State` to the variant. The remaining root route treats the enum as a module, but enum type-body members are not module exports, so these previously supported anchored variant references cannot resolve, including when used as method receivers. The visibility correction needs to preserve type continuation when the final prefix resolves to a type.
