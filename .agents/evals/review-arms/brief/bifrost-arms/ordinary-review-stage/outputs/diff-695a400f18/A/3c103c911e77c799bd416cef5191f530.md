- [P2] Preserve type continuation for explicitly anchored enum paths — crates/bifrost-rust/src/resolution.rs:1114-1115
  When a variant or associated item is referenced through an explicit anchor, such as `crate::State::Unit` or `self::State::Tuple(...)`, `bare_qualified_route` is false, so this change removes the final type-prefix continuation and treats `State` as a module segment. Enum members live in the type's member scope rather than module exports, so these paths no longer resolve to their constructors and their receiver methods cannot be resolved either. This also regresses explicitly anchored associated-item paths that previously used the same continuation.
