## Paths
- Supplying a resolution session sends `php_expression_type_fqn` directly to the bounded evaluator before its expression-kind dispatch (`crates/bifrost-analysis/src/analyzer/usages/get_definition/php.rs:234`). The bounded callback route passes `session.scope_step` into the shared callback finder (`crates/bifrost-analysis/src/analyzer/usages/get_definition/php.rs:2133`), whereas the unbounded route supplies an always-true step callback (`crates/bifrost-analysis/src/analyzer/usages/get_definition/php.rs:2627`).
- The new callback finder uses `resolve_php_function_node` (`crates/bifrost-php/src/graph/syntax.rs:524`), which resolves through function aliases (`crates/bifrost-php/src/aliases.rs:565`). Its structured callable resolver produces namespace-primary/global-fallback candidates for unqualified names without aliases, and exact candidates otherwise (`crates/bifrost-php/src/aliases.rs:702`).
- Inverted scanning records references, walks children, and only then seeds an assignment (`crates/bifrost-php/src/graph/inverted.rs:153`, `crates/bifrost-php/src/graph/inverted.rs:163`). Its assignment evaluator reaches the new subscript branch through `assignment_value_type_fq_name` (`crates/bifrost-php/src/graph/inverted.rs:476`, `crates/bifrost-php/src/graph/syntax.rs:224`, `crates/bifrost-php/src/graph/syntax.rs:1854`).
- For an instance call, inverted scanning uses the inferred receiver to select a declared callable and records that callable's FQN and member range (`crates/bifrost-php/src/graph/inverted.rs:300`, `crates/bifrost-php/src/graph/inverted.rs:308`). This is a downstream route for the callback-element result produced at `crates/bifrost-php/src/graph/syntax.rs:1819`.
