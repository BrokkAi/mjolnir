## Paths
- Batched modeled-target resolution calls `dispatch_many_at_bounded`, which parses one source snapshot, resolves callee references, expands imported external callees, and passes each outcome through `apply_call_target_outcome` to the changed adjudication assignment (crates/bifrost-analysis/src/analyzer/usages/effects.rs:392; crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:502; crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:564; crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:1121).
- Exact dispatch can construct unresolved lookups directly for unsupported languages, parse outcomes, or call locations; this route uses a default-initialized adjudication flag rather than `apply_dispatch_outcome_with_flags`, and its status enters the changed coverage projection (crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:495; crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:1033; crates/bifrost-analysis/src/analyzer/usages/effects.rs:486).
- The empty-arm branch records result-contract coverage through `record_result_contract_coverage`, which emits an `Incomplete` diagnostic; `CodeQueryResult::completion` reads that impact, and execution maps the diagnostic code to `AnalysisIncomplete` (crates/bifrost-rql/src/structural/search/effects.rs:485; crates/bifrost-rql/src/structural/search/effects.rs:1329; crates/bifrost-rql/src/structural/search/results.rs:195; crates/bifrost-rql/src/structural/search/execution.rs:1139).
- File sorting and contiguous preparation run inside `apply_pipeline_step`, called with the execution state's caches and semantic context; candidate expansion later consumes those prepared lookups, whereas full contract expansion obtains dispatch through `semantic.dispatch_at_source` (crates/bifrost-rql/src/structural/search/pipeline.rs:388; crates/bifrost-rql/src/structural/search/pipeline.rs:961; crates/bifrost-rql/src/structural/search/effects.rs:641).
- Artifact release at file transitions is gated by `can_start_artifact_windows`, which requires empty semantic caches and zero retained bytes. Its release method clears artifacts and live retention while retaining cumulative work; target-window release also runs on cancellation and loop completion (crates/bifrost-rql/src/structural/search/pipeline.rs:983; crates/bifrost-rql/src/structural/search/pipeline.rs:1004; crates/bifrost-rql/src/structural/search/pipeline.rs:2785; crates/bifrost-rql/src/structural/search/semantic.rs:1140; crates/bifrost-rql/src/structural/search/semantic.rs:1151).

## Value flow
- `lexical_definition_outcome` produces `Resolved` with no declaration targets and a lexical definition; dispatch uses that lexical value to set adjudication, while its existing empty-target status handling adds an unresolved boundary consumed by the modeled coverage projection (crates/bifrost-analysis/src/analyzer/usages/get_definition/mod.rs:1891; crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:1121; crates/bifrost-analysis/src/analyzer/usages/call_relations.rs:1186; crates/bifrost-analysis/src/analyzer/usages/effects.rs:488).
- Workspace target arms come from `modeled_procedure_key_for_unit`, which requires a callable, nonsynthetic declaration, exactly one persisted signature, a receiver contract, and a qualified owner; targets without such keys contribute to the residual count used to select `Unmodeled` (crates/bifrost-analysis/src/analyzer/usages/effects.rs:449; crates/bifrost-analysis/src/analyzer/usages/effects.rs:516; crates/bifrost-analysis/src/analyzer/usages/effects.rs:1492).
- The empty-open-lookup check calls `may_name_result_contract`, whose inventory insertion and lookup use only `(language, member, parameter_count)`, without `summary.target.has_receiver` or call receiver applicability; receiverless summaries and receiver calls with the same tuple share an inventory entry (crates/bifrost-rql/src/structural/search/effects.rs:263; crates/bifrost-rql/src/structural/search/effects.rs:283; crates/bifrost-rql/src/structural/search/effects.rs:492).
- Target-window preparation reads `analyzer.indexed_source`, sends report references to `modeled_call_targets_for_shapes`, and stores answers under their site IDs. Consumption checks both the window's file and site ID; the resolver batch derives call spans from those reports (crates/bifrost-rql/src/structural/search/effects.rs:292; crates/bifrost-rql/src/structural/search/effects.rs:476; crates/bifrost-rql/src/structural/search/effects.rs:614; crates/bifrost-analysis/src/analyzer/usages/effects.rs:396).
- The changed corpus completion assertion runs against a fixture that registers embedded packs and activates Go models. Its existing query chains candidate discovery into contract validation with a one-file semantic limit and expects one result and one materialization (tests/suite_bench_policy/go_result_contract.rs:52; tests/suite_bench_policy/go_result_contract.rs:1055; tests/suite_bench_policy/go_result_contract.rs:1077; tests/suite_bench_policy/go_result_contract.rs:1087).
