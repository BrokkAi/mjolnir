## RQL tool

The `rql_query(query, page=1)` tool is the permitted network call. Keep using
grep and source reads with the same checklist. Send one RQL query at a time,
using the reference and the additional menu steps below. The response gives
rows in stable order and reports `total`, `page` and `pages`. To read another
page of the same answer, repeat the query with that page number. Read the
anchored source whenever you need more context for a row.
