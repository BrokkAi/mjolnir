# Assignments for the Go port's runtime packages

Each file here is one unit of work: one or a few Go packages that stand in for
Rust libraries. To start one, give an agent (or a person) this instruction:

    Work in the repository root. Read
    `.agents/docs/go-port/brief-runtime-package.md` and follow it exactly. Your
    assignment is `.agents/docs/go-port/briefs/<name>.md`.

The common brief says what to read, where the Rust sources are, how to use the
oracle and what to report. `.agents/plans/port-mjolnir-to-go.md` (Progress)
records which assignments are done.
