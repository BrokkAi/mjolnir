# Test-and-fix campaign, 2026-09-30

Agent-facing runbook for a live regression pass over `mj` after the 55 commits that landed between the close of the 09-29 campaign (`3b8bb7d2`) and the campaign commit `6a2a0713` (2.24.0 plus fixes). It follows `.agents/docs/test-and-fix-2026-09-29.md` (the *09-29 runbook*): the coordinator (Opus) builds binaries and writes one card per track; **Sonnet** workers test live in private tmux servers and record findings; **workers do not fix anything**. The coordinator triages, dispatches fix agents in isolated worktrees, cherry-picks onto `master`, validates, and pushes each validated fix to `origin/master` (the user asked for that on 2026-09-30).

Differences from 09-29, set by the user on 2026-09-30:

- Real tracks use the **targets and profiles of the user's live config** (`~/.config/mjolnir/config.toml`), copied into a **separate named instance** per track. Remote targets included: `precision-3260` (bare, yolo), `morannon-raw` (bare, guardian), `morannon-podman` (podman on morannon), `podman` (local podman), `macbook` (bare over SSH). `aws-runson` (EC2) is left out: it costs money per launch and nothing in the range changed EC2-specific code.
- Budget: prefer the profile with the most remaining weekly quota; skip a profile under 10% weekly. The 30% rule of 09-29 is dropped. Claude sessions use Sonnet 5.5 (`claude-sonnet-5-5`), Codex sessions use Luna (`gpt-5.6-luna`), Claude children use `claude-haiku-4-5-20251001`.
